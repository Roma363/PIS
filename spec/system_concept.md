# Опис задуму системи: GoUptime

## 1. Загальне призначення
GoUptime — мікросервіс моніторингу доступності мережевих ресурсів (URL) за протоколами HTTP/HTTPS.

## 2. Ключові сутності
- **Endpoint:** URL цільового сервера, ліміт тайм-ауту (мс).
- **ProbeResult:** HTTP-код відповіді, затримка відповіді (LatencyMs), підсумковий статус ("UP" або "DOWN").

## 3. Базовий сценарій та критерій доступності
1. Виконується запит до цільової адреси та фіксується час відповіді й HTTP-код.
2. Критерій статусу "UP": HTTP-код відповіді успішний (діапазон 2xx або 3xx) ТА час відповіді (LatencyMs) не перевищує встановлений ліміт тайм-ауту (TimeoutMs). В усіх інших випадках — статус "DOWN".
