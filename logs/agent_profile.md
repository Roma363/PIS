# Профіль кодингового агента

- **Назва:** GitHub Copilot
- **Клас інструменту:** IDE-integrated AI Coding Agent.
- **Спосіб доступу:** Локальний робочий простір у IDE з контекстним аналізом відкритих файлів проєкту.
- **Дозволені операції:** Читання специфікації (/spec), генерація коду у /src та /tests, внесення правок за вказівками.
- **Політика перевірки:** Human-in-the-Loop — обов'язкова верифікація через git diff розробником перед фіксацією коміту.
